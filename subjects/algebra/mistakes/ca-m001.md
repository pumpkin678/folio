:::original
使用“$A[x]$ 是 PID”证明 Jac 与 Nil 的关系。
:::

:::correction
只有在某些特殊情形（例如 $A=k$ 是 field）$A[x]$ 才是 PID；一般 $\mathbb Z[x]$ 不是 PID。
:::

:::counterexample
$(2,x)\subseteq\mathbb Z[x]$ 不能由单个多项式生成。
:::

:::reviewtask
闭卷解释为什么理想 $(2,x)\subseteq\mathbb Z[x]$ 不是主理想，然后不用 PID 假设完成 [CA-Q002](ref:CA-Q002) 的证明。
:::
